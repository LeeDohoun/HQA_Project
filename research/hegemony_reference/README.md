# 헤게모니·주도주 참고 자료 정리

동부증권 X-book 『투자의 定石』 세 편(2011.05, 2016.03, 2016.10)을 읽고 원칙, 정량 기준, 사례, 필요한 데이터, 정성 판단 요소를 쪽수와 함께 정리한 문서입니다. 원문 PDF는 저장소에 넣지 않습니다.

이 자료는 **아이디어 출처**입니다. 그대로 따라 하지 않고, 검증 가능한 가설로 바꿔 `research/experiments/`에 사전 등록한 뒤 같은 기준으로 검증합니다. 문서 자체의 검증에는 생존편향, 거래비용 미반영, 짧은 기간, 내부 불일치가 있으므로 수치를 근거로 쓰지 않습니다.
