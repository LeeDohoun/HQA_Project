## 0. 한눈에 보기

**목표**: 소액 개인 자금으로 거래비용과 세금을 뺀 뒤에도 수익을 내는 전략을 찾고, 검증된 것만 운용합니다. 그 과정 전체를 재현할 수 있는 기록으로 남깁니다.

**핵심 전략**: 기관이 들어오기 어려운 저유동성·소형주 영역에서 "누가, 왜 나에게 돈을 주는가"에 답할 수 있는 작은 우위를 여러 개 찾습니다. 각 우위는 따로 검증하고, 통과한 것만 묶어서 운용합니다.

**출발점**: [멀티에이전트 구조 재검토](../research/backtesting/agent_architecture_review/README.md)에서 다음을 확인했습니다.
- LLM 점수는 무작위 점수와 구분되지 않았습니다.
- 규칙 점수도 벤치마크를 일관되게 이기지 못했습니다.

따라서 이 시스템에서 LLM은 **판정을 통과할 때까지 측정 도구로만** 씁니다.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 1. 데이터 계층   가격(전종목)·공시·재무·뉴스·수급·분봉·공모·대체 데이터 │
│                  모든 기록에 "처음 관측한 시각"과 "사용 가능 시각"      │
├──────────────────────────────────────────────────────────────────────┤
│ 2. 연구 계층     사전 등록 → 평가 도구(IC·이벤트·대조군·유동성·용량)    │
│                  → 실험 대장(시도 횟수 포함) → 판정                    │
├──────────────────────────────────────────────────────────────────────┤
│ 3. 전략 계층     A 구조적 수급 │ B 이벤트 │ C 대체 데이터 │ D 팩터     │
│                  E 가격 괴리 │ F 장중(연구 트랙)                       │
│                  공통 모듈: 국면·테마 필터                            │
├──────────────────────────────────────────────────────────────────────┤
│ 4. LLM 계층      텍스트 → 정해진 형식의 특징값 (전략마다 따로 검증)     │
│                  권한은 단계적으로 획득 (섀도 → 제안 → 제한된 자율)     │
├──────────────────────────────────────────────────────────────────────┤
│ 5. 배분 계층     통과한 전략만 편입, 위험 예산 배분, 성과 저하 시 축소   │
├──────────────────────────────────────────────────────────────────────┤
│ 6. 실행·위험 계층  비중·손절·한도·비용 모델·중단 스위치 (코드로 강제)   │
├──────────────────────────────────────────────────────────────────────┤
│ 7. 운영 계층     섀도 → PAPER → 소액 실계좌 → 확대, 감시와 감사 기록    │
└──────────────────────────────────────────────────────────────────────┘
```

## 1. 운영 원칙

1. **모든 전략은 "누가, 왜 나에게 돈을 주는가"에 답해야 합니다.** 예: 강제로 팔아야 하는 사람, 늦게 반응하는 사람, 제도 때문에 못 사는 사람. 답이 없으면 연구하지 않습니다.
2. **판정 기준은 실험 전에 씁니다.** 결과를 본 뒤 기준, 구간, 지표를 바꾸지 않습니다.
3. **규칙 기준선과 무작위 대조군을 항상 같이 돌립니다.**
4. **관측치가 많은 지표로 판단합니다.** 기간별 수익률 몇 칸이 아니라 IC, 이벤트 단위 초과수익, 분위 포트폴리오를 씁니다.
5. **모든 결과를 유동성 구간별로 나누고 용량을 계산합니다.** 작은 돈의 우위가 어디에 있는지 보기 위해서입니다.
6. **LLM 결과는 학습 오염이 없는 데이터로만 판정합니다.** 모델 학습 시점 이후 데이터와 앞으로 쌓을 데이터만 씁니다.
7. **백테스트와 실전은 같은 코드를 씁니다.** 전략 코드는 하나이고, 데이터 공급원과 주문 대상만 바꿉니다.
8. **최종 한도 점검과 중단 스위치는 LLM 밖의 코드가 담당합니다.** 어떤 단계에서도 예외가 없습니다.
9. **실패한 실험도 지우지 않습니다.** 시도 횟수는 판정 기준 자체에 반영됩니다 (3.4절).

### 2.2 시점 규칙 (모든 데이터 공통)

- 모든 기록은 `observed_at`(시스템이 처음 본 시각), `available_at`(의사결정에 쓸 수 있는 시각), `source`, `revision`을 가집니다.
- 백테스트와 실전 모두 `available_at <= 의사결정 시각`인 기록만 씁니다.
- 날짜만 있는 과거 공시는 **다음 거래일 시가부터** 사용 가능한 것으로 봅니다.
- 정정 공시와 재무 수정치는 원본을 덮어쓰지 않고 새 버전으로 쌓습니다. 기존 수집 파이프라인 규칙을 그대로 따릅니다.
- 현재 테마 목록을 과거에 소급하지 않습니다.

### 3.2 사전 등록과 실험 대장

- 실험 하나마다 `research/experiments/<실험ID>/preregistration.md`를 **실행 전에** 커밋합니다. 담을 내용: 가설, 돈을 주는 쪽, 데이터 구간, 지표, 통과 기준, 변형 수, 예상 비용.
- `research/experiments/registry.csv`에 모든 시도를 기록합니다 (실험ID, 전략군, 변형 수, 결과, 판정, 날짜). 실패도 기록합니다.

### 3.3 평가 도구 (전 전략 공통)

| 도구 | 내용 |
| --- | --- |
| IC | 의사결정 시점마다 점수 순위와 이후 1·5·20일(또는 1·3개월) 수익률 순위의 상관. 평균, t-통계, 연도별 안정성 |
| 분위 포트폴리오 | 점수 5분위별 비용 차감 수익률. 상하위 차이 |
| 이벤트 연구 | 이벤트 단위 초과수익(시장 대비)과 날짜 군집 t-통계 |
| 무작위 대조군 | 같은 분포의 무작위 점수 30개 이상 ([agent_replay.py](../backtesting/agent_replay.py) 방식을 일반화) |
| 유동성 구간 | 20일 평균 거래대금 기준 4구간 (1억 미만 / 1~10억 / 10~100억 / 100억 이상)별로 위 지표를 모두 따로 계산 |
| 용량 | 주문 금액 ≤ 20일 평균 거래대금의 1% 조건에서 전략 전체에 넣을 수 있는 최대 금액 |
| 비용 민감도 | 비용 모델의 1배, 1.5배, 2배에서 성과 |

### 3.4 연구 판정 기준

| 판정 | 기준 |
| --- | --- |
| 설계·검증 통과 | 비용 차감 후 성과 > 0. 핵심 지표 t > 2, 변형을 20개 넘게 시도했으면 t > 3. 무작위 대조군 상위 5%. 최소 관측 수 충족 (이벤트 300건 이상, 또는 리밸런싱 36회 이상). 비용 1.5배에서도 성과 > 0 |
| 보류 구간 통과 | 같은 방향, 비용 차감 후 > 0, 크기가 설계 구간의 절반 이상 |
| LLM 특징값 채택 | 같은 전략의 규칙 특징값만 쓴 버전 대비 개선이 위 기준을 충족. 판정은 학습 시점 이후·전진 데이터로만 |

## 4. 전략 계층

### 4.1 공통 전략 계약

모든 전략은 아래 형식을 따르고, 같은 코드로 백테스트와 실전을 돌립니다.

| 항목 | 내용 |
| --- | --- |
| `strategy_id`, `sleeve` | 전략 식별자, 전략군 (A~F) |
| `thesis`, `counterparty` | 가설과 "돈을 주는 쪽" |
| `universe` | 대상 종목 규칙 (유동성 구간 포함) |
| `inputs` | 사용 데이터와 각 데이터의 `available_at` 규칙 |
| `decision_time` | 의사결정 시각 (예: 장 마감 후 16:30) |
| `generate(as_of) -> list[TargetPosition]` | 결정론적 함수. 같은 입력에 항상 같은 출력 |
| `entry` / `exit` | 진입·청산 규칙 (6장 실행 규칙을 따름) |
| `capacity_krw` | 3.3절 방식으로 계산한 최대 운용 금액 |
| `stage` | 수명주기 단계 (8장) |
| `preregistration` | 사전 등록 문서 경로 |

### 4.2 전략군과 첫 가설

| 전략군 | 첫 가설 | 돈을 주는 쪽 | 데이터 | LLM | 우선순위 |
| --- | --- | --- | --- | --- | --- |
| **A1 보호예수 해제** | 해제 물량 비중이 큰 종목은 해제일 전후 초과수익이 마이너스 → 롱 전략의 **제외 필터**. 해제 후 반등은 별도 가설 | 해제 후 파는 기존 주주 | DART (의무보유 해제), 일봉 | 없음 | 1 |
| **A2 CB·BW 전환 물량** | 전환 가능 물량 비중이 큰 종목은 전환 가능일 이후 약세 → 제외 필터 | 전환 후 매도하는 채권자 | DART (전환사채 발행·전환청구) | 없음 | 1 |
| **A3 지수 정기변경** | 공개 규칙으로 계산한 코스피200·코스닥150 편입 예상 종목은 발표 전후 초과수익 | 지수를 따라야 하는 펀드 | 전종목 일봉, 지수 구성 | 없음 | 2 |
| **A4 공모주** | 증권신고서 특징(수요예측 경쟁률, 의무보유확약 비율, 유통 가능 물량)으로 청약 여부와 상장일 매도 시점을 고르면 기대값이 플러스 | 낮게 정한 공모가 | 증권신고서, 상장일 분봉 | L2 | 3 |
| **B1~B2 공시 이벤트** | 공시 유형과 구조화 수치(예: 공급계약 금액 / 직전 매출)가 이후 1~20일 초과수익을 예측 | 늦게 반응하는 투자자 | DART, 일봉 | 없음 | 1 |
| **B3 LLM 공시 분류** | LLM의 방향·새로운 정보 여부·예상 밖 정도가 B2 대비 추가 설명력을 가짐 | 위와 같음 | DART, 뉴스 | L1 | 2 (전진 데이터 필요) |
| **B4 잠정실적 후 추세** | 잠정실적이 직전 분기·전년 대비 크게 개선된 종목은 이후 추세 지속 | 실적을 늦게 반영하는 투자자 | DART 잠정실적, 재무 | 없음 | 2 |
| **C1 수출 잠정치** | 관세청 10일 단위 품목별 수출 증가율이 해당 품목 수출주의 다음 기간 수익률을 예측 | 데이터를 늦게 보는 투자자 | 관세청, 일봉 | L4 (품목 → 종목 연결) | 2 |
| **C2 검색량** | 네이버 검색량 급증이 소비재·테마주의 단기 관심과 수익률을 예측 | 관심이 늦게 붙는 투자자 | 데이터랩, 일봉 | L4 | 3 |
| **D 팩터** | 시장 전체에서 모멘텀(12-1개월), 퀄리티(ROE, 부채비율), 저변동성을 월 1회 낮은 회전율로 운용 | 위험 감수의 대가 (알파 아님) | 전종목 일봉, 재무 | 없음 | 1 (기준선) |
| **E 가격 괴리** | 우선주·보통주 괴리가 과거 범위를 크게 벗어나면 회귀 (매수 쪽만) | 일시적 수급 불균형 | 일봉 | 없음 | 4 |
| **F 장중** | 7장 별도 트랙 | 느린 사람 투자자 | 분봉, 공시 시각 | 일부 | 연구 트랙 |

시스템은 **매수 전용**입니다. 개인 공매도는 조건과 제약이 많기 때문입니다. 시장 하락 위험은 나중에 인버스 ETF나 코스피200 선물로 헤지하는 방식을 따로 검증합니다. 제외 필터(A1, A2)는 독립 전략이 아니라 다른 전략의 종목 범위에 적용합니다.

### 4.3 공통 모듈: 국면·테마 필터

- **역할**: 전략들이 쓸 "허용 테마·업종 목록"과 시장 국면(위험 선호, 위험 회피)을 매주 만듭니다. 수익원이 아니라 범위를 좁히는 필터입니다.
- **규칙 신호**: 테마 상대강도(20·60일), 확산도(20일선 위 종목 비율), 거래대금 비중 변화, 뉴스·공시 관심도, 시장 확산도.
- **LLM**: L3로 그 시점 기준의 테마 구성을 만듭니다. 뉴스에서 새로 떠오르는 흐름을 추출합니다.
- **검증**: 테마 × 월 단위 IC를 무작위 테마 선택과 비교합니다. 통과하지 못하면 필터를 쓰지 않고 유동성 조건만 적용합니다.

## 5. LLM 계층

### 5.1 측정 도구 목록

| ID | 도구 | 입력 → 출력 | 쓰는 곳 |
| --- | --- | --- | --- |
| L1 | 공시·뉴스 이벤트 분류 | 원문 → {유형, 방향 −2~+2, 신규·후속·반복, 예상 밖 정도, 중요도, 확신도} | B3 |

| L3 | 테마 소속 분류 | 당시 사업보고서·공시 → {테마 목록, 근거 문장} | 국면·테마 필터 |

| L7 | LLM 단독 판단 전략 | 종목 자료 → 매수·보유·제외 판단 | 섀도 경쟁 후보 (5.3절) |

### 5.2 공통 규칙

- 모델 이름, 프롬프트 버전, 출력 형식(JSON 스키마)을 고정하고 기록합니다. 온도는 0입니다. 모든 결과를 캐시합니다.
- 공급자가 모델을 바꾸면 **새 버전으로 보고 다시 검증**합니다.
- 회사명을 가린 입력으로 같은 결과가 나오는지 확인합니다 (기억 의존 여부).
- 원문 텍스트는 신뢰하지 않는 입력으로 다룹니다 (본문에 숨은 지시문 방지).
- 월 LLM 예산 상한을 두고, 대량 실행 전에는 견적을 냅니다.

## 6. 배분과 실행·위험 계층

### 6.1 배분

- **편입 조건**: PAPER 단계를 통과한 전략만 실자금을 받습니다.
- **배분 방식**: 처음에는 전략별 위험(변동성) 동일 배분으로 시작합니다. 한 전략의 위험 비중은 최대 40%이고, 상관이 높은 전략끼리는 합산 한도를 둡니다.
- **감쇠 감시**:
  - 롤링 6개월 IC가 0 아래이거나 실현 성과가 기대 분포 하위 5%면 위험 예산을 절반으로 줄입니다.
  - 12개월간 이어지면 퇴출합니다.
- 용량(`capacity_krw`)을 넘는 자금은 배정하지 않습니다.

### 6.2 실행 규칙 (일봉 전략 기본값)

| 항목 | 기본값 |
| --- | --- |
| 진입 | 신호 확정 후 다음 거래일 시가. F-H2가 통과하면 그 방식(예: 첫 30분 VWAP)으로 교체 |
| 종목 수 | 전략당 10~20개 |
| 비중 | 변동성 역가중. 종목당 전략 자금의 10% 이하, 테마당 30% 이하 |
| 유동성 | 주문 금액 ≤ 20일 평균 거래대금의 1% |
| 청산 | ATR 기반 손절, 보유 기간 상한, 신호 소멸 시 청산 |
| 체결 불가 | 거래정지, 상·하한가 도달 종목은 백테스트에서도 체결 불가로 처리 |

### 6.3 비용 모델 (모든 백테스트와 실전 비교에 공통)

- 수수료: 증권사 실제 요율 (설정값)
- 매도 거래세: 0.20% (2026년 기준, 코스피·코스닥 공통. 연도별 세율표로 관리)
- 스프레드: 가격대별 호가 단위로 계산 (거래소 호가가격단위 기준, 구현 시 출처 확인)
- 추가 슬리피지: 유동성 구간별 가산
- 예상 왕복 비용: 소형주 기준 약 0.4~0.7%

### 6.4 계좌 위험 한도와 안전장치

- 일일 손실이 계좌의 2%를 넘으면 그날 신규 진입을 중단합니다.
- 최대 낙폭 10%에서 신규 진입을 중단하고 검토합니다. 15%에서 전체 청산 여부를 결정합니다.
- 주문 횟수 상한과 취소 비율 상한을 둡니다. 저유동성 종목에서 주문·취소를 반복하거나 호가 대비 과도한 주문을 내면 의도와 무관하게 시세조종으로 의심받을 수 있으므로 이를 막습니다.
- 수동 중단 스위치가 있습니다.
- 위 한도는 백엔드에서 LLM·전략 코드와 독립적으로 검사합니다. 기존 `PaperAccountGuard`, `TradeConditions`를 확장합니다.

## 7. 장중 연구 트랙 (F)

**전제**: B에서 공시 반응이 일봉으로 확인돼야 장중에 더 빨리 반응할 의미가 있습니다. 검증 가능한 가설만 다룹니다.

| 가설 | 내용 | 성격 | 데이터 | 가능 시점 |
| --- | --- | --- | --- | --- |
| H1 장중 공시 반응 | 공시 최초 관측 후 N분 안에 규칙대로 진입하면 당일 종가나 정해진 시간 청산까지 비용 차감 수익 | 수익원 | 공시 최초 관측 시각(전진 수집만 가능), 분봉 | 수집 시작 후 3~4개월 |
| H2 진입 시점 개선 | 일봉 전략 종목을 시가 대신 09:30이나 첫 30분 VWAP에 사면 체결 가격이 나아짐 | 비용 절감 | 분봉 (과거 약 1년 백필) | 백필 직후 |
| H3 VI 이후 패턴 | 코스닥 소형주 변동성완화장치 발동 후 30분 수익률에 일관된 방향이 있음 | 탐색 | 분봉, VI 기록 | 백필 직후 |

- **백필 범위**: 전 종목 전 기간이 아니라 일봉 전략 신호일과 이벤트일 ±1일로 좁힙니다. API 초당 호출 제한 안에서 나눠 받습니다. 모의투자 도메인에서 이 API가 동작하는지 먼저 확인합니다.
- **시뮬레이션 규칙** (보수적):
  - 신호 다음 분봉에서 체결합니다.
  - 매수는 분봉 고가나 VWAP에 스프레드를 더합니다.
  - 체결 수량은 분봉 거래량의 일정 비율 이하로 제한합니다.
  - 세금과 수수료를 반영합니다.
- **실측**: KIS 모의투자는 장중 슬리피지를 과소평가합니다. 시뮬레이션을 통과하면 거래당 고정 소액의 실계좌로 실제 체결 차이를 잽니다.
- **판정**: 사전에 정한 거래 수(예: 200회) 이상에서 거래당 비용 차감 수익 > 0, t > 2, 실측 슬리피지가 시뮬레이션 가정 이내.
- **실전 전환 조건**: 지금 monitor는 REST로 20초마다 조회합니다. H1을 실매매로 옮기려면 웹소켓 체결 수신이 필요합니다.

| 21~ | A4 공모주, C2 검색량, E 가격 괴리, L5 확장. 감쇠 감시 운영 | H1 통과 시 웹소켓 실시간 체결 |

**판정 시점**:
- **D1 (5주차)**: D·B1·B2·A1·A2 중 하나라도 3.4절 기준을 넘는가? 하나도 없으면 가설을 다시 설계합니다. 두 번 반복해도 없으면 매매 수익 목표를 보류하고, 시스템과 연구 기록을 결과물로 정리합니다.
- **D2 (8주차)**: 보류 구간을 통과한 전략이 있는가? 있으면 섀도·PAPER로 진행합니다.
- **D3 (20주차)**: PAPER를 통과한 전략이 있는가? 있으면 소액 실계좌로 진행합니다. LLM 특징값과 L7은 전진 데이터에서 규칙 대비 개선이 확인될 때만 승격합니다.

## 12. 금지 사항 체크리스트

실험, 배포, 자금 투입 전에 확인합니다.

**데이터와 통계**
- [ ] 현재 테마 목록, 정정 후 재무 수치, 같은 종가 체결처럼 미래 정보를 쓰지 않았다
- [ ] 판정 기준과 구간을 실행 전에 커밋했고 결과를 본 뒤 바꾸지 않았다
- [ ] 보류 구간을 한 번만 봤다
- [ ] 시도한 변형 수를 실험 대장에 기록했다
- [ ] LLM 결과를 학습 기간 데이터로 판정하지 않았다
- [ ] 비용, 호가 차이, 체결 불가 종목을 반영했다
- [ ] 장중 전략을 모의투자 체결만으로 통과시키지 않았다

**돈과 위험**
- [ ] 판정을 통과하지 않은 전략에 실자금을 넣지 않았다
- [ ] 연승이나 손실 직후 금액을 바꾸지 않았다. 규칙 없는 물타기를 하지 않았다
- [ ] 레버리지(신용, 미수, 레버리지 ETF)를 쓰지 않았다
- [ ] 실전 중 파라미터를 고치지 않았다. 고쳤다면 새 전략으로 다시 검증한다

**시스템과 LLM**
- [ ] LLM에게 한도와 독립 검증이 없는 직접 주문 권한을 주지 않았다
- [ ] 실계좌 자동매매 차단을 판정 없이 풀지 않았다. 실계좌 키가 코드나 저장소에 없다
- [ ] 일일 손실 한도, 주문 횟수 상한, 수동 중단 스위치가 동작한다

**법적 문제**
- [ ] 신고나 등록 없이 남에게 돈을 받고 신호를 제공하거나 남의 계좌를 운용하지 않는다
- [ ] 반복 주문·취소나 과도한 호가 주문처럼 시세조종으로 보일 수 있는 패턴을 코드로 막았다
- [ ] 데이터 수집이 출처의 약관을 지킨다

**기록**
- [ ] 실패한 실험도 지우지 않고 남겼다
